# Run instructions

- Requires env variables for Twilio
- to run the server in terminal, run: uv run --env-file twilio.env python src/server.py
- to run the server with logs, run: uv run --env-file twilio.env python src/send.py +16476686246

- to run the website in terminal, run: uv run --env-file twilio.env streamlit run src/optin.py
